Generates the data for the [Module:SRPedia/Data](https://slimerancher.wiki.gg/wiki/Module:SRPedia/Data) page on the wiki.

## Usage
Run the `srpedia.py` script with the path to an exported `pedia.txt` file provides as the first argument. Alternatively, this file can be placed in this directory and the script can be run with no arguments and it will automatically use that file.

`pedia.txt` can be extracted from `resources.assets` under the path `Assets/Resources/i18n/LANGCODE/pedia`.
